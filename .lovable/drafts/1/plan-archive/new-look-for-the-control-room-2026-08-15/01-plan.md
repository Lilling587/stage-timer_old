# New look for the control room

Rebuild the `/admin` page as a "Tactical command" console — the direction you picked — using the locked design choices: charcoal base with an ember accent (#e85d3a), Sora headings with Manrope body text, and a sidebar layout.

Nothing about how the show runs changes. Every control you have today stays, in the same working order: add and edit speakers, reorder, set live, delete, Start / Pause / Reset / Next, the −5 / −1 / +1 / +5 minute nudges, blackout, clock toggle, message send and clear, the live stage preview, the admin-count badge, and the links to Companion setup and the stage view. Only the presentation changes.

## What the new page looks like

- **Left sidebar — run of show.** Compact add-speaker form at the top, then the speaker cards. The live speaker card is tallied with an ember left bar and a "Now speaking" label; upcoming speakers sit dimmed and reveal Set live / Edit / Delete on hover. Footer shows connection state and the number of admins connected.
- **Header.** "Command" wordmark, links to Companion setup and stage view, and a live sync status readout on the right.
- **Main area.** A large live stage preview panel at the top, then two control cards below: time adjustments on the left, transport (Start / Pause / Reset / Next) on the right with Start as the single ember button.
- **Right column.** Stage messaging panel with a textarea, Clear and Send, plus the clock toggle and the blackout button underneath.
